# Memories Architecture

## Phase 1 boundaries

Memories is a single-target, iPhone-only SwiftUI application generated by XcodeGen. It is local-first and uses Apple Photos as the only media source of truth. The app stores references, user-local state, curation history, and lightweight profile metadata through SwiftData, while leaving photos and videos in the system library.

## Layers

- `Sources/App`: app entry, dependency graph, root tabs, app composition
- `Sources/Core`: stable domain contracts, environment values, cross-feature primitives
- `Sources/DesignSystem`: theme tokens, Liquid Glass surfaces, motion, haptics, reusable controls
- `Sources/Features/*`: onboarding, feed, library, blocked, and profile UI
- `Sources/Persistence`: SwiftData models and repositories for local state
- `Sources/Services/Photos`: PhotoKit authorization, observation, fetches, and mock library seam
- `Sources/Services/Curation`: deterministic filtering, cycle tracking, and Smart Random baseline scoring
- `Sources/Services/Playback`: video and Live Photo playback coordination
- `Sources/Services/Sharing`: temporary export packaging and cleanup

## Data ownership

- Apple Photos owns media bytes and authoritative asset existence.
- SwiftData owns:
  - saved references
  - blocked references
  - viewed cycle history by filter signature
  - profile metadata
  - theme choice
  - avatar framing metadata
  - conservative recovery metadata

## Phase 1 flow

1. Onboarding captures name, avatar reference, privacy context, authorization, and theme.
2. PhotoKit-backed services enumerate eligible assets under the active filter.
3. `MemoryCurationEngine` derives a non-repeating cycle for a filter signature.
4. Feed playback loads current, previous, and next items only.
5. Library, Blocked, and Profile reuse the same local reference state and PhotoKit lookup path.

## Release strategy

Windows is not the authoritative iOS build environment. Local work focuses on repository correctness, scripts, tests, and workflow validity. GitHub Actions on macOS is the authoritative path for device builds and unsigned IPA artifacts.
